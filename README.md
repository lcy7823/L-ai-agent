# L-AI-Agent

一个基于 Spring AI 的智能AI助手平台，提供恋爱咨询、智能搜索、文档生成等多功能服务。

## 项目简介

L-AI-Agent 是一个集成多种AI能力的智能助手平台，旨在为用户提供智能化的问题解答和任务执行服务。项目结合了大语言模型、RAG（检索增强生成）知识库和多种实用工具，能够处理从日常咨询到复杂任务执行的多样化需求。

## 核心功能

### 1. 恋爱咨询助手
- **身份定位**：专业的恋爱心理专家
- **服务场景**：
  - 单身状态：社交圈拓展、追求心仪对象的困扰
  - 恋爱状态：沟通问题、习惯差异引发的矛盾
  - 已婚状态：家庭责任分配、亲属关系处理
- **功能特点**：
  - 支持多轮对话，记住历史聊天内容
  - 流式输出，实时展示AI回复
  - 自动生成恋爱建议报告

### 2. 智能知识库问答
- 基于 RAG 技术的智能问答系统
- 内置单身、恋爱、已婚状态的常见问题知识库
- 支持关键词重写和智能检索增强
- 提供精准的领域知识问答服务

### 3. 多功能AI助手（LiuManus）
一个全能型AI助手，配备多种工具可高效完成复杂任务：
- **网页搜索**：实时搜索互联网获取最新信息
- **PDF生成**：根据内容自动生成PDF文档
- **文件操作**：文件的创建、读取、写入等操作
- **资源下载**：从网络下载图片、文档等资源
- **终端操作**：执行系统命令完成各类任务

### 4. 图片搜索服务
- 独立的 MCP（Model Context Protocol）服务
- 提供图片搜索能力
- 支持 SSE 和 Stdio 两种通信模式

## 应用场景

- **恋爱咨询**：为用户提供专业的恋爱心理建议和解决方案
- **智能问答**：基于知识库的精准问答，解决特定领域问题
- **文档生成**：自动生成约会计划、报告等PDF文档
- **信息检索**：快速搜索网络信息并整理汇总
- **任务自动化**：通过AI智能分解和执行复杂任务

## 技术特点

- 基于 Spring Boot 3.5 + Spring AI 构建
- 支持同步调用和 SSE 流式输出
- 集成持久化对话记忆，支持多会话管理
- 支持多种AI模型接入
- 模块化设计，工具可灵活组合使用
